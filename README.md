# Vantage Download Site

A MediaFire-inspired Google Drive link converter built with React, Vite, Express, PostgreSQL, and Firebase Auth.

## Stack
- React + Vite frontend
- Express 5 API backend
- PostgreSQL + Drizzle ORM
- Firebase Auth (vantage-share)
- AdSense integration (ca-pub-6431906375099854)
- Social task wall, QR codes, dark mode, admin panel
